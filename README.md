# Unity 카드 배틀 MVP

유희왕에서 영감을 받은 Unity 2D 1인용 카드 배틀 프로토타입입니다.

현재 프로젝트는 아주 작은 MVP에 집중합니다. 카드 데이터, 덱 드로우, 손패 UI, 카드 선택, 몬스터 소환, 마법 카드 사용, 함정 카드 세트, 묘지 확인 흐름까지만 구현되어 있습니다.

## Unity 버전

- Unity 6000.4.8f1
- uGUI
- TextMesh Pro
- Universal Render Pipeline 2D

## 현재 구현된 기능

- `ScriptableObject` 기반 카드 데이터
- `CardType` enum
  - 몬스터
  - 마법
  - 함정
- 덱 셔플 및 시작 손패 5장 드로우
- `CardView` 프리팹 기반 손패 UI 생성
- 카드 정보 표시
  - 이름
  - 타입
  - 코스트 또는 레벨
  - 공격력 / 수비력
  - 일러스트
  - 설명
- 카드 hover 애니메이션 및 선택 표시
- 카드 드래그 앤 드롭 조작
- 몬스터 존 5칸
- 함정 존 5칸
- 턴 패널 및 드로우 버튼
- 손패가 많아질 때 자동 축소/정렬
- 마법 카드 사용 흐름
  - `Draw Scroll`은 실제로 카드 2장 드로우
  - 다른 마법 카드는 아직 로그만 출력
  - 사용 후 손패에서 제거
  - 내부 Graveyard 리스트에 추가
- 함정 카드 세트 흐름
  - 함정 존에 세트
  - 세트 후 손패에서 제거
- 묘지 UI
  - 묘지 카드 더미 형태로 표시
  - 마우스 hover 시 묘지 카드 수와 카드 이름 목록 표시
- 덱 UI
  - 덱 카드 더미 형태로 표시
  - 마우스 hover 시 남은 덱 장수 표시
- 기본 UI와 테스트 카드 생성을 위한 에디터 도구

## 아직 구현하지 않은 것

현재 MVP 범위에서 의도적으로 제외한 기능입니다.

- 전투 시스템
- 체인 시스템
- AI 상대
- 대부분의 실제 카드 효과
- 고급 연출 애니메이션

## 에디터 도구

Unity 상단 메뉴에서 사용할 수 있습니다.

```text
Tools > 기본 카드 프리팹 생성
Tools > 테스트 카드 데이터 생성
```

`기본 카드 프리팹 생성`은 다음 항목을 생성하거나 갱신합니다.

- Canvas
- EventSystem
- CardView 프리팹
- 손패 영역
- 몬스터 존
- 함정 존
- 턴 패널
- 카드 액션 버튼
- 필요한 Manager 오브젝트들

`테스트 카드 데이터 생성`은 현재 테스트용 카드 10장을 생성하거나 갱신합니다.

## 실행 방법

1. Unity에서 프로젝트를 엽니다.
2. `Assets/Scenes/SampleScene.unity` 씬을 엽니다.
3. Unity 상단 메뉴에서 아래 메뉴를 실행합니다.

```text
Tools > 기본 카드 프리팹 생성
Tools > 테스트 카드 데이터 생성
```

4. 씬의 `DeckManager` 오브젝트를 선택합니다.
5. `Starting Deck`에 테스트 카드 에셋들을 넣습니다.
6. Play 버튼을 누릅니다.

## 현재 게임 흐름

1. 덱이 셔플됩니다.
2. 시작 손패 5장을 드로우합니다.
3. 몬스터 카드를 선택한 뒤 빈 몬스터 존을 클릭하면 소환됩니다.
4. 몬스터 카드를 빈 몬스터 존으로 드래그해도 소환됩니다.
5. 마법 카드를 선택한 뒤 `Use Card` 버튼을 누르면 사용됩니다.
6. 마법 카드를 `Use Card` 버튼이나 필드 존으로 드래그해도 사용됩니다.
7. 함정 카드를 선택한 뒤 `Set Trap` 버튼을 누르면 함정 존에 세트됩니다.
8. 함정 카드를 빈 함정 존이나 `Set Trap` 버튼으로 드래그해도 세트됩니다.
9. `Next Turn / Draw` 버튼을 누르면 턴이 증가하고 카드 1장을 드로우합니다.
10. 덱 카드 더미에 마우스를 올리면 남은 덱 장수를 확인할 수 있습니다.
11. 묘지 카드 더미에 마우스를 올리면 묘지 카드 수와 카드 목록을 확인할 수 있습니다.
